DON STREAMING

An open-source movie streaming platform for web and Android.

DON STREAMING is an independently branded streaming platform designed to make legally available movies accessible through a modern, user-friendly experience.

Project Vision

To build a reliable, accessible and affordable streaming platform that connects audiences with legally available entertainment.

Platforms

- Web application
- Android mobile application

Key Features

- Movie discovery and browsing
- User registration and secure accounts
- Free and premium membership options
- Online movie streaming
- Offline downloads where content rights permit
- Personal watchlists
- Watch history and viewing progress
- Administrative dashboard
- Subscription and payment management

Content Policy

DON STREAMING will only distribute or stream content obtained through:

- Properly licensed content providers.
- Verified public-domain sources.
- Other sources with documented permission for distribution.

Offline downloads will only be enabled where the applicable content rights permit them.

Technology Foundation

The proposed technology stack includes:

- Next.js and TypeScript — web application.
- React Native with Expo — Android application.
- Supabase and PostgreSQL — database and authentication.
- FFmpeg — video processing.
- Secure video hosting and content delivery infrastructure.
